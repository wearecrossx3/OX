# OX — origin × destination

Daily route tracker for Android by Frontpage Studios.

- Auto-detects bike/car trips (activity recognition) or start any trip manually
- Draws the route on a map (OpenStreetMap / CARTO tiles, no API key)
- Live speed, time, distance; trip history with route shapes
- Weekly averages, per-day chart, quickest/longest trips
- Walk tracking with path shape, steps estimate
- All data stays on the phone

Every push to `main` builds a signed APK in GitHub Actions and publishes it under Releases.
